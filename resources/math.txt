├─────────────────────────────────────────────────────────────┤
│ 1. COMANDOS BÁSICOS                                         │
├──────────────┬──────────────────────────┬───────────────────┤
│ Comando      │ Ejemplo                  │ Resultado         │
├──────────────┼──────────────────────────┼───────────────────┤
│ \num{1234.5} │ \num{1234.5}             │ 1.234,5           │
│ \num{3.1416} │ \num{3.1416}             │ 3,1416            │
│ \num{1e4}    │ \num{1e4}                │ 10.000            │
├──────────────┼──────────────────────────┼───────────────────┤
│ \SI{0.5}{\second}   │ \SI{0.5}{\second}   │ 0,5 s           │
│ \SI{200}{\hertz}    │ \SI{200}{\hertz}    │ 200 Hz          │
│ \SI{0.2}{\pascal}   │ \SI{0.2}{\pascal}   │ 0,2 Pa          │
│ \SI{1.45}{\pascal}  │ \SI{1.45}{\pascal}  │ 1,45 Pa         │
├──────────────┼──────────────────────────┼───────────────────┤
│ \si{\metre\per\second} │ \si{\metre\per\second} │ m/s       │
│ \si{\kilogram\metre\per\square\second}  │ → kg·m/s² (Newton)│
└──────────────┴──────────────────────────┴───────────────────┘

┌─────────────────────────────────────────────────────────────┐

┌─────────────────────────────────────────────────────────────┐
│ 4. UNIDADES COMPUESTAS Y POTENCIAS                          │
├─────────────────────────────────────────────────────────────┤
│ Se pueden combinar unidades con \cdot, \per, \square, etc.  │
│ Siempre dentro de \si o como argumento de \SI.              │
├──────────────┬──────────────────────────┬───────────────────┤
│ Ejemplo      │ Código                   │ Resultado         │
├──────────────┼──────────────────────────┼───────────────────┤
│ 10 m/s²      │ \SI{10}{\metre\per\square\second} │ 10 m/s²  │
│ 5 N·m        │ \SI{5}{\newton\metre}    │ 5 N·m             │
│ 3 kg·m/s²    │ \SI{3}{\kilogram\metre\per\square\second} │ 3 kg·m/s² (Newton) │
│ 1,2 m²       │ \SI{1.2}{\square\metre}  │ 1,2 m²            │
└──────────────┴──────────────────────────┴───────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 5. DEFINIR NUEVAS UNIDADES                                  │
├─────────────────────────────────────────────────────────────┤
│ Si necesitas una unidad no predefinida (\dB, \Hz ya existe), │
│ puedes declararla en el preámbulo (o en estilo.sty):        │
│ \DeclareSIUnit{\dB}{dB}                                     │
│ \DeclareSIUnit{\dBm}{dBm}                                   │
│ Luego: \SI{3}{\dB} → 3 dB                                   │
├─────────────────────────────────────────────────────────────┤
│ También puedes crear unidades con prefijos:                 │
│ \DeclareSIUnit{\mbar}{mbar}  (ya existe \milli\bar)         │
└─────────────────────────────────────────────────────────────┘
